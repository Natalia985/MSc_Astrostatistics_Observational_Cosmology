## Student use of Crete material

The student-facing course should link only to the **non-answer-key** Crete notebooks as the designated learning materials.

The Crete repository itself is public, so answer-key files remain technically visible there. Assessment therefore should not reproduce Crete exercises verbatim; the graded course tasks use different real observational datasets and scientific questions.

## Recommended weekly workflow

**Before lecture:** skim the linked Crete notebook.  
**During lecture:** follow the cosmology-focused instructor notebook.  
**Before lab:** complete specified Crete sections.  
**During lab:** apply the method to real cosmological/AGN data.  
**After lab on graded weeks:** complete the Extended Analysis in the same notebook.
