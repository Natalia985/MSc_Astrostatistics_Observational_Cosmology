# Lab Submission Guide

## Naming

`Surname_Name_LXX.ipynb`

## Graded lab submission

Submit:

1. completed `.ipynb`;
2. exported `.html` or `.pdf` of the same notebook.

No separate report is required.

## Reproducibility

Before submission:

- restart kernel;
- run all cells top-to-bottom;
- retain random seeds;
- label figures and units;
- state the exact dataset/table;
- remove debug output;
- do not hard-code results that should be computed.

## Required final section

### Scientific conclusion

300–500 words answering:

- What did you infer?
- What is the main numerical result?
- What uncertainty accompanies it?
- Which diagnostic supports it most strongly?
- What is the largest limitation?
- What claim would be unjustified?
